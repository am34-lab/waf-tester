問題をインポート

JSONファイルからインポート

KindleのCISSP問題集を手動でJSONに書き起こしてインポートできます。インポートした問題はブラウザに保存されます。

📂
クリックまたはドラッグ＆ドロップ
.json ファイルを選択

JSONフォーマット（配列形式）:

[
  {
    "domainId": 1,
    "question": "Which of the following BEST describes due care?",
    "options": [
      "Taking reasonable security precautions",
      "Conducting annual security audits",
      "Training all employees annually",
      "Documenting all policies"
    ],
    "correct": 0,
    "explanation": "Due care means taking reasonable precautions..."
  }
]

correct は 0〜3 の数値（選択肢のインデックス）
